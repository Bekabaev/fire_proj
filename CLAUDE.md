# fire_proj — правила для Claude Code

Проект: прогноз распространения степных пожаров Казахстана. Подробности и текущие задачи — в `HANDOFF.md`
и `PROGRESS.md`.

## Два агента
Над проектом работают два агента: на Windows-ПК (`win-pc`) и на ноутбуке с Debian (`laptop`). Они
связываются через `AGENT_LOG.md` и скилл `/sync`.
- В начале сессии запусти `/sync`: подтяни изменения и прочитай, что сделал другой агент.
- После каждого законченного куска работы снова запусти `/sync`, чтобы записать итог в журнал и сделать push.

## Правила
- Не печатай и не коммить секреты: `task1_dataset/.firms_key`, `prod/.tg_token`.
- Email пользователя никуда не отправляй.
- Пушить можно только в `prod-engine`; в `main` — только с явного согласия пользователя.
- Сохраняй прогресс: commit и push после каждого законченного куска (бывают отключения света).
- Бюджет ограничен: долгие задачи запускай в фоне, проверяй редко.
- Обучение и eval не запускать одновременно (было падение по памяти).
- Отвечай пользователю по-русски, коротко и по делу.
